Política de privacidad de Frank

Última actualización: 26 de octubre de 2026.

Quién usa Frank

Frank es un asistente personal privado. Su único usuario es su dueño, que es también quien lo administra. No hay otros usuarios ni registro público.

Qué datos de Google usa

  • Gmail: leer y organizar los correos del propio dueño cuando él lo pide.
  • Google Calendar: leer los eventos del propio dueño y, si él lo pide, crear o modificar eventos en su calendario.

Dónde se guardan

Las autorizaciones y los datos necesarios se guardan cifrados o con acceso restringido en un servidor privado del dueño. No se publican.

Con quién se comparten

Los datos no se venden, no se usan para publicidad y no se comparten con terceros. Para generar respuestas, partes del contenido pueden procesarse con el proveedor de inteligencia artificial que usa el asistente, solo para atender pedidos del propio dueño.

Uso de datos de Google

El uso de la información recibida de las API de Google se ajusta a la Política de Datos del Usuario de los Servicios de API de Google, incluidos los requisitos de Uso Limitado.

Cómo revocar el acceso

El acceso se puede revocar en cualquier momento desde myaccount.google.com/permissions.
